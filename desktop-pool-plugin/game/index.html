规则要点

开球：母球置于头线后，击散球堆。开球进球不换手。
分组：第一杆合法进袋后确定花色（全色 1-7 / 花色 9-15）。
犯规：母球落袋、先碰错球、空杆、碰球后无球吃库 — 对手获得手中球，可自由摆放母球。
获胜：清完己方花色后，合法打进 8 号球即获胜；提前打进 8 号则判负。

物理

滑动 / 滚动 / 旋转三段摩擦模型，球-球恢复系数 0.95，库边 0.85， 带切向摩擦与库边接触点高度计算，因此薄球有真实的 throw 偏移、 低杆能拉回、高低塞吃库后变线。
