# zhizhen-pool · 桌面台球 黑八

## 这是什么

一个跑在 DSH Web UI 里的三维美式 8 球台球桌。点会话输入框左侧的「台球」按钮（或按 `⌥P`）展开成全屏，关掉就回到对话。

它不是一个"看起来像台球"的演示：球的每一次碰撞、每一次吃库、每一次低杆回拉都由物理引擎实时计算，规则按 WPA 标准 8 球判定。

## 玩起来是什么感觉

- **开球**：母球摆在开球线后，按空格蓄力砸向球堆，球会真实地散开
- **瞄准**：拖着鼠标转，辅助线会画出幽灵球位置和目标球走向；按住 `Shift` 微调，精度到 0.01°
- **杆法**：拖左下角白球到不同位置——打下半部是低杆，撞球后母球会往回缩；打上半部是高杆，母球跟着走；打左右两侧是塞，吃库后角度会变
- **对局**：你和 AI 轮流打，先清完自己那组（全色 / 花色）再打进 8 号就赢

## 技术要点

### 物理

三段式摩擦模型（滑动 → 滚动 → 自旋衰减），参数取自真实台球实测值：

| 量 | 值 |
| --- | --- |
| 球半径 / 质量 | 28.575 mm / 170 g |
| 滑动摩擦 μ_s | 0.20 |
| 滚动摩擦 μ_r | 0.0125 |
| 球-球恢复系数 | 0.95 |
| 库边恢复系数 | 0.85 |

球-球碰撞带切向冲量，所以薄球会有真实的 throw 偏移；库边接触点高于球心，所以撞库会"咬"一下。

### 渲染

three.js，全部素材程序化生成（台布编织纹、木纹年轮、球的号码圈），没有任何贴图文件。光照是三盏吊灯的局部强光——台球厅那种"台面很亮、周围很暗"的对比。

### 音效

Web Audio 实时合成：撞球是宽带瞬态叠加 1.8k/3.2k/4.6k Hz 三个高 Q 模态，库边是低通噪声加 120 Hz 闷响，落袋是塑料碰撞加下坠音。速度和亮度随撞击强度变化，每次调用有 ±3% 随机化，连打不会像复读机。

### 插件集成

游戏跑在 shadow root 里，样式和 id 不会漏到 DSH 界面；关闭覆盖层时会回收所有动画帧、事件监听和 AudioContext。
