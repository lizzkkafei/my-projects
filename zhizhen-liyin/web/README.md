# 理音 Liyin Studio

> 从一次关于梦的对话长出来的音乐创作工作台：Logic Pro 式的一体化 DAW 界面，中文优先，AI 原生。
> 默认工程《镜湖》直接继承上一轮会话：散文 → 歌词 → MIDI 旋律 → ACE-Step 三个生成版本。

## 快速开始

```bash
cd liyin-studio
python3 serve.py            # 默认 http://127.0.0.1:8090/
```

浏览器打开 **http://127.0.0.1:8090/** 即可。

- 也可以直接双击 `index.html`：编曲、播放、混音、导出都可用；但**素材池载入与 AI 调用需要本地服务**（浏览器禁止 `file://` 下的 fetch 本地音频/跨域请求），**录音**也需要 http 安全上下文。
- AI 生成按钮通过 `serve.py` 的 `/ace/*` 反向代理调用本机模型，避免跨域。
- 如果本机 ACE-Step 没启动，界面仍可用；「模型」页里有启动命令。

## 它是什么

一个 **MVP 级桌面 DAW 原型**：目标是在同一个应用里完成
**写词 → 编曲 → 录音 → 混音 → 导出母带**，中间不离开工作台。

设计原则：

1. **创作流不断**：切换编排 / 混音 / 录音 / 钢琴卷帘不丢上下文；所有编辑自动保存。
2. **智能辅助可调**：贴合原意、创意开放、编曲密度三个滑杆直接喂给编曲生成器；AI 生成的结果可继续手改。
3. **中文体验优先**：界面、术语、歌词结构、模型提示词全中文；歌词排版用宋体。

## DSH 会话入口

同目录的 `../liyin-workbench/` 是一个 DSH 插件包：注册会话输入框的「理音」按钮与全屏 overlay iframe，宿主半把工作台挂在 `/api/liyin/*`（同源，录音/音频/AI 均可用），并代理 `/api/liyin/ace/*` 到本机 ACE-Step。安装与重启说明见 `../liyin-workbench/README.md`。

## 架构

```
liyin-studio/
├── index.html      应用外壳与静态面板
├── styles.css      Logic 风格设计令牌与组件
├── data.js         《镜湖》工程数据（歌词 / 和弦 / 旋律 / 素材）
├── engine.js       Web Audio 引擎：走带、合成器、鼓机、发送、电平、录音、离线渲染
├── ai.js           智能辅助：本地生成器、ACE-Step 客户端、混音/和弦建议
├── notation.js     五线谱渲染（Canvas 大谱表，1423 行，零依赖，符杠/调号/加线/dpr 全档位）
├── app.js          应用状态、编排/钢琴卷帘/鼓机/混音器 UI、导出、自动保存
├── serve.py        本地静态服务 + /ace 反向代理
├── assets/audio/   会话产出的音频素材（3 个 AI 版本 + 旋律小样 + 60 秒 demo）
└── _tools/         生成 demo 与测试脚本（非应用运行必需）
```

数据流：`data.js → App.project → Engine.setProject() → AudioContext 调度`；
UI 编辑写回 `App.project` → 自动保存 localStorage → 能力地图中的「撤销历史」同步。

## 智能辅助怎么用

右侧「智能辅助」：

1. 输入一句主题（默认已填《镜湖》的梦境），选风格。
2. **生成歌词**：本地模板生成器，按主题关键词与情绪出主歌/预副歌/副歌/桥段结构。
3. **生成编曲**：按风格生成和弦走向、钢琴琶音、贝斯、铺底、旋律与鼓组，直接写入工程。
4. **写入工程**：保存当前参数。
5. **调用模型生成整首歌**：真正调用本机 ACE-Step 1.5（`acestep-v15-turbo` + `acestep-5Hz-lm-0.6B`），约 3–5 分钟；生成完自动进「主唱」轨，期间可以继续编辑。

滑杆含义：

- **贴合原意**：文本对编曲走向的影响权重（越高越保守）。
- **创意开放**：旋律音域跳跃与和声外音的允许度。
- **编曲密度**：音符密度、鼓组复杂度。

「智能混音建议」：按乐器角色分配增益/声像/发送（人声 −3 dB 为焦点，铺底退到 −15 dB）。

### 启动本机模型

```bash
cd ../ACE-Step-1.5
export PATH="$PWD/.bin:$PATH" ACESTEP_LM_BACKEND=mlx ACESTEP_INIT_LLM=true \
       HF_HOME="$PWD/.hf" HF_MODULES_CACHE="$PWD/.hf/modules"
.venv/bin/acestep-api --host 127.0.0.1 --port 8001 \
  --lm-model-path acestep-5Hz-lm-0.6B --download-source modelscope
```

## 已知限制

- 浏览器内音源为合成音色，不是采样库；听感与商业 DAW 有差距，但工程结构、编辑逻辑与导出链路是真实的。
- 生成式 AI 是协作工具：结果需要人挑、人改；模型对 BPM/调性是软约束。
- 本地生成依赖 `ACE-Step-1.5/` 模型权重（约 7.3 GB），首次启动需要加载。
- 录音需要麦克风授权；无麦克风时只能使用已有素材。
- 工程自动保存于浏览器 localStorage；清缓存会丢本地状态（可用「导出工程 JSON」备份）。

## V1 已完成

**导出链路**
- **分轨导出**：每轨独立 WAV 打包 ZIP（含分轨说明），支持统一响度增益。
- **响度规范**：−14 LUFS（流媒体）/ −16 LUFS（播客）/ −9 LUFS（响母带），ITU-R BS.1770 简化实现 + −1 dBFS 峰值保护，导出时显示 before → after。
- **主唱干声 / 伴奏**：一键分别导出。

**混音自动化**
- 每条轨道的 音量 / 声像 / 混响 / 延迟 四条自动化曲线，可画控制点、拖动、双击删除。
- 内置「淡入淡出」「副歌渐强」形状生成；播放时实时写入 AudioParam，离线渲染用 linearRamp 复现。
- 拖拽时实时更新曲线，与推子互不打架（有自动化的参数由曲线接管）。

**五线谱**
- Canvas 大谱表：高音/低音谱号（墨迹边界精确缩放）、12 调调号、拍号、加线、符干方向、附点、符尾、**按拍分组的符杠**（十六分双杠 + 斜率拟合）、临时升降号、空小节全休止符、终止线。
- 和弦符号与段落标记对齐小节；每行按音符密度自适应 4/8 小节；播放时高亮当前小节并自动滚动到所在行。
- 三种视图：旋律 / 钢琴（高低声部拆两谱表）/ 全部；可一键导出 PNG。

**多 take 合成**
- 录几遍同一段，按权重混合成一条（自动归一化 + tanh 软限幅防削波）。
- 支持「自动对齐起点」与逐条独听（S）。

**DSH 会话入口**
- `@local/liyin-workbench` 插件把工作台嵌回会话：输入框「理音」按钮，**⌥M**（⌥L 保留为别名），同源托管 + `/api/liyin/ace/*` 代理本机 ACE-Step。
